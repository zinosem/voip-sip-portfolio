---

## 🛠️ Core Competencies

- **SIP Protocol & VoIP**: SIP signaling analysis, RTP/SRTP media streams, SDP negotiation, T.38 FoIP (Fax over IP).
- **Packet Analysis**: Deep Wireshark/tcpdump PCAP inspection — diagnosing call failures (401, 408, 480 errors), jitter, latency, and packet loss.
- **PBX Administration**: Asterisk & FreePBX setup — SIP trunks, extensions, call routing, NAT traversal, and audio troubleshooting.
- **Linux & Networking**: TCP/IP, DNS, DHCP, NAT, firewall rules, shell scripting for automated diagnostics.
